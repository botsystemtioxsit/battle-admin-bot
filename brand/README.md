# Значки проектов (brand)

Единое место для значков всех наших проектов. Нужен значок — берите отсюда,
не рисуйте и не переименовывайте заново.

У каждого проекта до двух значков:

- **`<проект>-app.png`** — для установленного приложения (Android .apk, Electron на компьютере, Telegram).
- **`<проект>-browser.png`** — для открытого в браузере: тот же значок + **оранжевый глобус** в углу.
  Так сразу видно, что это сайт в браузере, а не приложение.

|---|---|---|---|
| Тролль-Баттл (игра) | `game-app.png` | `game-browser.png` | красный, чёрная четырёхконечная звезда |
| ВидеоЧат | `videochat-app.png` | `videochat-browser.png` | зелёный, микрофон |
| Админ-панель | `panel-app.png` | `panel-browser.png` | серый, шестерёнка |
| TIOXSIT Launcher | `launcher-app.png` | — | синий, стрелка «скачать» |
| Пустой (для будущих экспериментальных приложений) | `blank-app.png` | `blank-browser.png` | белый, пустой круг (сейчас: приложение «Lock Screen Custom Plus») |

## Важные замечания

- **У лаунчера нет значка для браузера.** Лаунчер — программа для Windows, в браузере его не открывают.
  Вариант с глобусом (№8 в исходном архиве) сознательно **не добавлен**.
- **Размер исходников 71×71 пикселей.** Владелец разрешил увеличивать, поэтому рабочие значки
  (`public/logo*.png`, `desktop/icon.*`, `android/.../mipmap-*`) сделаны из них скриптом
  `brand/make_icons.py` (увеличение + лёгкая резкость). Если когда-нибудь появятся значки
  побольше или SVG — подставить их как исходники и запустить скрипт заново, руками PNG не править.
- Внизу каждого значка видна тёмная полоса-градиент. Если это не задумано — пересохранить исходник без неё.

## Как пересоздать рабочие значки

Из корня репозитория (нужен Python и `pip install pillow`):

```bash
python3 brand/make_icons.py brand/panel-app.png --browser brand/panel-browser.png \
    --web public --desktop desktop --android android/app/src/main/res
```
Для игры — `game-*`, и ещё `--bg-png` (у игры фон адаптивного значка лежит файлами). Пример команды — в начале самого скрипта.

## Где какой значок уже используется

- **Админ-панель** (этот репозиторий): `public/logo.png` (приложение) и `public/logo-browser.png` (браузер) —
  вкладка браузера и шапка панели сами выбирают нужный; `desktop/icon.png|ico` — Electron; `android/.../mipmap-*` — APK.
- **Игра** (репозиторий `index.html`): то же самое со значками `game-*`.
