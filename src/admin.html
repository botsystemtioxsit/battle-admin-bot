Приложения
Та же панель, без входа заново — на любом устройстве. Desktop-версия (Windows/Linux) обновляется сама, без переустановки.
.tar.gz — самый надёжный вариант
Ничего не ставит в систему — просто распаковка и запуск. Работает даже там, где .deb уже не ставится (часть свежих образов ChromeOS).
На ChromeOS браузер скачивает файл в «Загрузки» самого ChromeOS — это НЕ то же самое, что ~/Downloads внутри Linux (Crostini), и по умолчанию Linux эту папку не видит. Если tar пишет «No such file or directory»: открой приложение «Файлы» → «Загрузки» → правый клик по файлу → «Copy to Linux» (или проверь ls /mnt/chromeos/MyFiles/Downloads/*.tar.gz).
tar -xzf battle-admin-desktop-*.tar.gz
cd battle-admin-desktop-*/
./battle-admin-desktop
# если пишет "error while loading shared libraries: libnss3.so...":
sudo apt-get update
sudo apt-get install -y libnss3 libnspr4 libatk-bridge2.0-0 libatk1.0-0 libgtk-3-0 libgbm1 libasound2 libxss1 libxtst6 libdrm2 libxkbcommon0
# если apt ругается на libasound2 (переименован на новых Debian/Ubuntu):
sudo apt-get install -y libasound2t64
AppImage
Тоже без установки, но нужен FUSE — если не хватает, поставится одной командой. Из трёх форматов только AppImage умеет обновляться сам (autoUpdater поддерживает его на Linux официально).
chmod +x *.AppImage
./*.AppImage
# если ругается на FUSE:
sudo apt-get install -y libfuse2 || sudo apt-get install -y libfuse2t64
.deb (обычная установка)
sudo dpkg -i battle-admin-desktop_*_amd64.deb

Опасная зона
Обслуживание платформы и полный сброс перед бета-тестом — действие для тех, кому явно выдано право «Система» (см. «Настроить права» в карточке игрока), а два самых критичных пункта — только для Супердоступа. У твоей текущей роли (—) сейчас нет прав даже на безопасную часть этой вкладки.
Проверка ключей (role-gateway)
Выдача роли admin/superadmin идёт через отдельный Cloudflare Worker — эта кнопка проверяет, что у него на месте оба секрета и что они совпадают с тем, что сейчас задеплоено в database.rules.json. Если что-то красное — выдача роли не заработает, пока не поправишь именно этот пункт.
Режим обслуживания (для обновлений/тестов)
Закрывает основной сайт для обычных игроков — они увидят экран «Идут технические работы». Модератор/Админ/Супердоступ заходят как обычно, чтобы проверить обновление до того, как открыть его всем.
Включён
Закрытый бета-тест
Новым визитёрам (у кого ещё нет аккаунта) вместо мгновенного входа показывается экран заявки — принять их сможет только тот, у кого включено право «Заявки на закрытый бета-тест» (см. вкладку «Заявки»). У кого аккаунт уже есть — их не касается, заходят как обычно.
Включён
Значки-награды
Выдаёт выбранный значок абсолютно всем текущим аккаунтам разом — например, чтобы восстановить значок после сброса старой версии, которая их стирала. Если у разных игроков раньше были разные значки — точную историю (кому что выдавали) смотри в «Журнале».
Гостевые аккаунты
Гости (аккаунты вида guest_...) создаются автоматически, когда приложение открывают не из Telegram, и обычно сами чистятся через 24 часа после создания. Эта кнопка удаляет их все прямо сейчас, не дожидаясь суток.
Опасная зона — сброс истории
Это действие доступен только Супердоступу.
Необратимо удаляет всю историю боёв — matches, battles и очереди поиска (queue, refereeQueue) — и обнуляет у ВСЕХ игроков очки, месячный рейтинг и статистику. Аккаунты, роли, списки друзей/заявок и значки-награды не трогает — значки остаются как есть, это не сезонная статистика, а память о том, что игрок был в проекте. Делай это только перед настоящим стартом бета-теста, когда вся текущая история — просто тестовый мусор.
config/resetSecret ещё не задан — сначала впиши пароль в поле выше ("Задать новый пароль сброса") и сохрани его.
Аварийный режим
Это действие доступен только Супердоступу.
Полностью закрывает и основной сайт, и эту панель — для ВСЕХ, включая Админов и Модераторов. Доступ сохранится только у Супердоступа, и заодно остановятся ежедневные автобэкапы в battle-data-admin-bot — отдельно их выключать не нужно. Используй при реальном инциденте (взлом, утечка данных, критический баг — не для обычных обновлений, для них есть режим обслуживания выше) — либо чтобы законсервировать проект на неопределённый срок: снять тумблер и вернуть всем доступ (и автобэкапы) можно в любой момент, ничего не удаляется и не ломается необратимо.
